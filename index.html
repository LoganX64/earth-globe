BHARAT ATLAS - Interactive 3D India Globe

An interactive 3D globe of India, rendered in the browser on an HTML canvas using official Survey of India cartography. Explore every state boundary, highlight Indian states, drop location pins, and embed the globe in any website.

Features

  • Orthographic 3D globe with official state borders, J&K, Ladakh and the outer boundary
  • Auto-rotation with adjustable speed and direction; drag to spin and scroll to zoom
  • Eleven cartography themes across light and dark modes
  • Hover or click a state to highlight it
  • Location pins for Indian cities plus worldwide search
  • Layer toggles for the graticule, atmosphere, starfield and state borders
  • Zero-chrome iframe embed for portfolios, Webflow, WordPress and any HTML site

Embedding the globe

Add the globe to any page with a single iframe, configured entirely through query parameters: 

<iframe src="https://earth-globe-nine.vercel.app/embed.html?onlyIndia=true&mode=dark" width="500" height="500" style="border: none; border-radius: 16px;"></iframe>

Getting started

The globe loads with auto-rotation, drag and zoom enabled. Use the Globe Customizer panel to switch themes, toggle map layers, place pins and pick a state. Keyboard shortcuts: SPACE pause or resume rotation, X clear the active pin, ESC close the details panel, C toggle the customizer, T switch light/dark map themes and R reset the view.
